# mapadosorixas

Enciclopédia interativa dos Orixás — catálogo, fichas com fontes citadas e grafo de conexões entre tradições (Candomblé e suas nações, Umbanda, culto iorubá, Santería/Lucumí, vodun, inquices).

- Contexto e regras do projeto: [`CLAUDE.md`](CLAUDE.md)
- Estado atual e próximas tarefas: [`docs/ESTADO.md`](docs/ESTADO.md)
- Plano completo (fases, cronograma, critérios de aceite): [`docs/PLANO.md`](docs/PLANO.md)
- Catálogo de fontes: [`data/fontes/catalogo.json`](data/fontes/catalogo.json) — validar com `python3 scripts/validar_fontes.py`
- Relatórios de pesquisa: [`docs/pesquisa/`](docs/pesquisa/) — bloqueios a resolver em [`PENDENCIAS.md`](docs/pesquisa/PENDENCIAS.md)
